Privacy Policy - Meme AI Uploader

Last updated: 21 October 2026

Who uses this tool

Meme AI Uploader is a personal tool used only by its owner to upload their own videos to their own YouTube channels. It has no other users.

What it accesses

  • Permission to upload videos to the signed-in YouTube channel (YouTube API scope youtube.upload).
  • The signed-in channel's ID and name, read only to check that a video goes to the right channel (YouTube API scope youtube.readonly).

What it stores, and where

Only the sign-in token Google issues and the channel ID, kept on the owner's own computer (as Windows user environment variables). Nothing is sent to any server other than Google's own servers. No data is sold, shared or used for advertising, and no analytics or tracking is used.

How to remove access and data

Access can be revoked at any time on the Google security settings page. The stored token is deleted by removing those environment variables from the computer.

YouTube and Google

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
